# Resources

This challenge uses a small set of strong resources instead of many parallel courses.

## Java

### Dev.java

Primary reference for modern Java.

Use it for:

- language features;
- collections;
- generics;
- streams;
- records;
- concurrency;
- JVM concepts.

### Head First Java — 3rd Edition

Use when a concept needs a more intuitive explanation.

Do not read it linearly as a requirement.

Skip GUI-focused sections unless curiosity makes them relevant.

### Effective Java — Joshua Bloch

Use as a decision-making reference.

High-value topics include:

- dependency injection;
- object equality;
- immutability;
- composition;
- interfaces;
- generics;
- streams;
- `Optional`;
- exceptions;
- concurrency.

Do not try to memorize every item.

### MOOC.fi Java Programming

Source of selected exercises.

The challenge does not require completing the entire course.

### Exercism Java Track

Additional focused practice and feedback.

Use when another implementation exercise would strengthen a concept.

## Resource Rule

Use resources in this order whenever practical:

1. documentation;
2. strong books;
3. structured course material;
4. reputable community explanations;
5. AI assistance.

The purpose is not to avoid AI.

The purpose is to preserve the ability to verify what AI says.
